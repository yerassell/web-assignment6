# web-assignment6

https://yerassell.github.io/web-assignment6/

This repository includes four parts of tasks completed. Each html file has a navigation bar that links to each others.

## Brief description
- index.html contains the Task 0 and Task 1. It is connected to task0.js and task1.js
- part2.html contains the Tasks 2-4. They are connected to task2.js, task3.js and task4.js
- part3.html contains the Tasks 5-7. It is connected to task5.js, task6.js and task7.js
- part4.html contains the Tasks 8-10. It is connected to task8.js, task9.js and task10.js
- part5.html contains the Task 11.

## Instructions
To run the project:
1. Clone this repository to your local device (if Git is downloaded in your device)
   ```bash
   https://github.com/yerassell/web-assignment6.git
   ```
   If Git is not downloaded in your device, click the green button **Code** ath the right top of the repository, select **download ZIP**, unzip the downloaded file.
2. Open the project folder in your device
3. Open the html file inside any task folder. It will open and display the website on your default web browser. The navigation bar will guide you to other tasks.
